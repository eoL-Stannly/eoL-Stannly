# On-Page SEO Optimization

## Overview
On-page SEO involves optimizing individual pages to rank higher and earn more relevant traffic. It covers content, HTML source code, and user experience signals.

## Title Tags
- Include primary keyword near the beginning
- Keep under 60 characters to avoid truncation in SERPs
- Make it compelling — titles affect click-through rate (CTR)
- Each page must have a unique title
- Format: `Primary Keyword - Secondary Keyword | Brand`

## Meta Descriptions
- Not a direct ranking factor, but impacts CTR
- Keep under 155 characters
- Include primary keyword (Google bolds matching terms)
- Write as a call-to-action or value proposition
- Unique per page; if too many to write manually, leave blank (Google auto-generates)

## Heading Structure
- One H1 per page, containing the primary keyword
- Use H2s for major sections, H3s for subsections
- Headings should form a logical outline of the content
- Include keyword variations naturally in subheadings
- Don't skip heading levels (H1 → H3 without H2)

## Content Optimization
- **Keyword placement**: First 100 words, headings, naturally throughout
- **Semantic richness**: Cover related entities, synonyms, and subtopics (use tools like Clearscope, Surfer, or Frase)
- **Content depth**: Comprehensively answer the search query
- **Readability**: Short paragraphs, bullet points, clear language
- **Freshness**: Update publish dates when content is significantly refreshed
- **E-E-A-T signals**: Author bylines, credentials, cited sources, original research

## Image Optimization
- Descriptive, keyword-relevant alt text on all images
- Compress images (WebP format preferred)
- Use descriptive file names (seo-audit-checklist.webp, not IMG_1234.jpg)
- Implement lazy loading for below-fold images
- Set explicit width and height attributes (prevents CLS)

## Internal Linking
- Link to related content with descriptive anchor text
- Update old content to link to new relevant pages
- Place contextual links within body content (more valuable than sidebar/footer)
- Audit for broken internal links regularly

## URL Optimization
- Short, descriptive, keyword-inclusive
- Lowercase, hyphens between words
- Remove unnecessary words (a, the, and, of)
- Avoid changing URLs unless absolutely necessary (redirect if you do)
