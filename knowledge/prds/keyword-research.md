# PRD: Keyword Research & Opportunity Analysis Deliverable

**Version:** 1.0
**Last Updated:** 2026-02-12

---

## Deliverable Overview

A comprehensive keyword research document that identifies organic search opportunities, maps keywords to pages, and provides a prioritised action plan for content and optimisation efforts.

## Deliverable Type

`Keyword Research & Opportunity Analysis`

## Required Sections

### 1. Executive Summary
- 3–5 sentence overview of key findings
- Top 3 opportunities highlighted
- Total keyword universe size and addressable volume
- Current organic visibility baseline

### 2. Methodology
- Data sources used
- Date range of data collection
- Tools and scoring methodology
- Any limitations or caveats

### 3. Keyword Universe Overview
- Total keywords analysed
- Breakdown by intent type (informational, commercial, transactional, navigational)
- Search volume distribution (head, mid-tail, long-tail)
- Current ranking distribution (positions 1–3, 4–10, 11–20, 21–50, 51–100, not ranking)

### 4. Topic Clusters
For each cluster:
- **Cluster name** and theme
- **Primary keyword** with volume and difficulty
- **Supporting keywords** (5–20 per cluster) with data
- **Mapped page** (existing URL or "content gap")
- **Cluster opportunity score**

### 5. Quick Wins
- Keywords ranking positions 4–20 with low difficulty
- Current page URL and current position
- Recommended action (optimise title, add content, build links)
- Estimated traffic uplift

### 6. Content Gap Analysis
- Keyword clusters with no existing page
- Recommended content type for each gap
- Search volume potential
- Suggested content title and format
- Priority ranking

### 7. Competitor Keyword Overlap
- Keyword overlap matrix (client vs. top 3 competitors)
- Unique competitor keywords (they rank, client doesn't)
- Shared keywords where client underperforms
- Competitive advantage keywords (client wins)

### 8. Recommendations
Each recommendation must include:
- **Priority** (High / Medium / Low)
- **Action** — specific, implementable instruction
- **Impact** — expected outcome with estimated metrics
- **Effort** — implementation complexity (Low / Medium / High)
- **Owner** — suggested team member or role

### 9. Appendix: Full Keyword List
- Complete keyword dataset in tabular format
- Columns: keyword, volume, difficulty, current position, intent, mapped URL, cluster, opportunity score

## Acceptance Criteria

- [ ] Minimum 50 keywords analysed per topic cluster
- [ ] All keywords have volume, difficulty, and intent classification
- [ ] Quick wins section contains minimum 10 opportunities
- [ ] Content gaps are mapped to specific keyword clusters
- [ ] Recommendations are actionable with clear owners
- [ ] Data is no more than 30 days old
- [ ] Executive summary accurately reflects the data

## Output Formats

- **Primary:** Markdown report with embedded data tables
- **Optional:** CSV export of full keyword list, JSON for programmatic use
