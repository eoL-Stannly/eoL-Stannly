# PRD: Performance Analysis & Reporting Deliverable

**Version:** 1.0
**Last Updated:** 2026-02-12

---

## Deliverable Overview

A data-driven performance report that analyses organic search metrics, identifies trends and anomalies, and provides actionable insights to guide SEO strategy decisions.

## Deliverable Type

`SEO Performance Analysis`

## Required Sections

### 1. Executive Summary
- 3–5 key takeaways for the reporting period
- Headline metrics with period-over-period change
- Top win and top concern highlighted
- Overall trajectory assessment (improving, stable, declining)

### 2. Reporting Period & Data Sources
- Reporting period dates
- Comparison period (MoM, QoQ, YoY)
- Data sources used (GSC, GA4, rank tracker, etc.)
- Any data gaps or caveats

### 3. Organic Traffic Analysis
| Metric | This Period | Previous Period | Change | YoY Change |
|--------|-----------|----------------|--------|------------|
| Sessions | ... | ... | ...% | ...% |
| Users | ... | ... | ...% | ...% |
| Clicks (GSC) | ... | ... | ...% | ...% |
| Impressions | ... | ... | ...% | ...% |
| Average CTR | ... | ... | ...pp | ...pp |

- Traffic breakdown by device type
- Traffic breakdown by page group/section
- Top 10 gaining pages with drivers
- Top 10 declining pages with diagnosis
- New pages generating traffic

### 4. Keyword & Ranking Performance
- Total keywords tracked and movement summary
- Keywords by position bracket (1–3, 4–10, 11–20, 21–50, 51–100)
- Notable ranking improvements (top 10 movers up)
- Notable ranking declines (top 10 movers down)
- Featured snippet performance
- New keyword rankings acquired
- Share of voice / visibility score trend

### 5. Conversion & Business Impact
- Organic conversion metrics:
  - Conversion rate (overall and by page group)
  - Total conversions / leads / revenue from organic
  - Revenue per organic session (if e-commerce)
- Assisted conversion contribution
- Comparison to other channels (organic share of total)
- ROI metrics where calculable

### 6. Technical Health Snapshot
- Core Web Vitals summary (LCP, INP, CLS — pass/fail by page group)
- Indexation health (submitted vs. indexed count, trend)
- Crawl error trends
- Critical technical issues (if any)

### 7. Competitive Landscape
- Visibility comparison against key competitors
- Competitor ranking movements on shared keywords
- New competitive threats identified
- Competitive opportunities (competitor weaknesses)

### 8. Actions Taken This Period
- Summary of SEO activities completed
- Correlation to observed metric changes where possible
- Activities in progress / pending

### 9. Recommendations & Next Steps
Each recommendation must include:
- **Priority** (High / Medium / Low)
- **Action** — specific, implementable recommendation
- **Impact** — expected metric improvement
- **Effort** — implementation complexity
- **Timeline** — when to implement

### 10. Appendix
- Full data tables
- Methodology notes
- Glossary of metrics

## Acceptance Criteria

- [ ] All headline metrics have period-over-period comparisons
- [ ] Traffic analysis includes both GSC and Analytics data
- [ ] Ranking data covers all tracked keywords
- [ ] Insights explain "why" not just "what"
- [ ] Recommendations are tied to specific data observations
- [ ] Executive summary is understandable by non-SEO stakeholders
- [ ] All numbers are verified against source data

## Output Formats

- **Primary:** Markdown report with data tables
- **Optional:** HTML report with charts, CSV data export, PDF executive summary
