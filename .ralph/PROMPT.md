# LLM Agents Office - Development Goals

## Vision
Create an interactive visual workspace showing LLM agents as cartoon characters
working in an office environment. The agents collaborate autonomously to complete
software engineering tasks, powered by a shared knowledge base.

## Core Goals
1. Multi-agent system with specialized roles (planner, researcher, coder, reviewer, tester, documenter)
2. Visual office UI with animated cartoon characters at desks
3. Knowledge base integration for grounding agent responses
4. Ralph Wiggum bash loop for autonomous continuous operation
5. Real-time monitoring dashboard

## Architecture
- Frontend: React (Vite) with CSS animations
- Backend: Node.js/Express with WebSocket for real-time updates
- Agent System: Orchestrator pattern with task queue
- Knowledge Base: Keyword-indexed document store
- Automation: Ralph Wiggum bash loop with safety mechanisms
